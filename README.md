# AirLink

Windows x64 无线投屏接收软件。

1. 解压完整目录，双击 AirLink.exe，保留 runtime 文件夹。
2. 电脑与 Apple设备连接同一局域网。
3. 点击“开始接收”，在 Apple设备的控制中心打开“屏幕镜像”，选择 AirLink-电脑名称。

保留高清、HEVC、稳定优先和重连接收功能。窗口比例设置不显示；恢复首次播放窗口自动适配，沿用此前截图估算的约 1.59:1 比例，不是实时识别视频比例。手动最大化后仍可能留边，其他设备或竖屏尚需适配。

画质选项是请求规格，实际编码、分辨率和码率由 Apple设备协商决定。稳定优先可能影响音画同步，观看视频时可取消。发生卡死可点击“重连接收”，然后重新连接屏幕镜像。诊断日志在 logs 文件夹中，不录制画面声音。

首次运行如系统提示，请允许专用网络访问，必要时完成 Bonjour 服务安装。受 DRM 保护的视频可能无法显示。

接收组件为 UxPlay Windows 2.0.0.1736，保留第三方许可证。组件来源：https://github.com/leapbtw/uxplay-windows/releases/tag/2.0.0.1736

源码构建：运行 build.ps1。AirLink.ico 嵌入可执行文件。


设置记忆：画质、稳定优先和有效设备名称会自动保存至 %LOCALAPPDATA%\AirLink\preferences.xml，下次启动自动恢复。首次运行或配置损坏时使用默认设置；启动软件不会自动开始接收。
